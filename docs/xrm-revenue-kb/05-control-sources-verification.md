# Сверка с авторитетными источниками (контрольный слой)

Спорные/непокрытые тезисы из [реестра расхождений](02-contradictions-and-caveats.md) проверены по **авторитетным источникам** (стандарты учёта ФСБУ 5/2019 и IAS 2, справочники CFI/ACCA/CIMA/Investopedia/Wikipedia), а не по второму блогеру. Принцип: стандарт/учебник бьёт мнение автора канала.

Сырые ресёрчи со всеми ссылками: [sources/control/](sources/control/) (`R1_ebitda`, `R2_sebestoimost`, `R3_spisanie_zapasov`).

## В1. EBITDA — определение (в канале не было дано)

**Определение:** EBITDA (Earnings Before Interest, Taxes, Depreciation & Amortization) — прибыль до вычета процентов, налогов и амортизации ОС и НМА; мера операционной прибыльности ядра бизнеса, очищенная от структуры финансирования, налогового режима и учётной политики по активам. Разг. «грязная прибыль».

**Две формулы (фиксируем обе):**
```
EBITDA = Чистая прибыль + Проценты + Налоги + Амортизация        (снизу вверх)
EBITDA = Операционная прибыль (EBIT) + Амортизация               (сверху вниз)
Проверка-тождество:  EBITDA − Амортизация = EBIT
```

**❗ Правка к таблице МаркФинансиста:** в его ОПУ строка подписана **«EBITDA (операционная прибыль)»** — это **некорректно**. EBITDA ≠ операционная прибыль: они различаются ровно на амортизацию (EBITDA = EBIT + амортизация). Совпадают только когда амортизация = 0.
→ В продукте: либо строка **«EBITDA»** отдельно, либо **«Операционная прибыль (EBIT)»** — но не отождествлять их. В тексте корректно писать «EBITDA = операционная прибыль + амортизация».

**Дисклеймер (для honesty продукта):** EBITDA ≠ денежный поток (не учитывает капзатраты, оборотный капитал, уплаченные проценты/налоги); это не GAAP/МСФО-показатель; при публичной отчётности требует сверки с чистой прибылью (SEC).

Источники: CFI, Wikipedia (EBITDA), Wall Street Prep, SoFi, МоёДело. Investopedia недоступна для фетча — положения подтверждены перекрёстно.

## В2. Себестоимость — «забудь про себестоимость» верно НАПОЛОВИНУ

Тезис автора: «себестоимость вредна, считай только маржинальную прибыль; постоянные расходы не разносить». Проверка:

**Два контура учёта — две задачи (это ключ):**
- **Управленческий контур (решения):** маржинальный подход (contribution = выручка − переменные) действительно предпочтительнее для оперативных решений — цена сделки, брать/не брать заказ, add/drop продукта, точка безубыточности. Это мейнстрим CIMA/ACCA/CFI/HBR, **МаркФинансист здесь прав**. Общие постоянные расходы по позициям размазывать не надо — условная аллокация искажает решения (прибыльная по contribution позиция выглядит убыточной).
- **Бухгалтерский/внешний контур (обязателен по закону):** полную себестоимость считать **нужно** — требование **ФСБУ 5/2019** и **IAS 2** для оценки запасов (незавершёнка, готовая продукция), налога и внешней отчётности. Производственные постоянные накладные распределяются по нормальной мощности; управленческие и сверхнормативные расходы в себестоимость запасов НЕ включаются (идут в период) — тут ФСБУ 5/2019 п.26 совпадает с интуицией автора.

**❗ Правка:** заменить категоричное «забудь про себестоимость» на **«не путай контуры»**: для решений — маржинальная прибыль; для отчётности/налога/оценки запасов — полная себестоимость (обязательна). Буквальное «забудь» → невозможно закрыть баланс + недооценка точки, ниже которой бизнес не окупает постоянные затраты.

**Для позиционирования AXIOM:** усиливает «XRM = управленческий контур» (выручка, маржинальность, contribution по клиентам/направлениям), но продукт должен явно оговаривать, что не заменяет бухгалтерский расчёт себестоимости по ФСБУ 5/2019.

Источники: AccountingTools, aCOWtancy (CIMA P1 / ACCA MA), CFI, HBR, IFRS Community (IAS 2), КонсультантПлюс (ФСБУ 5/2019 п.26), Минфин РФ, Клерк.

## В3. Методы списания запасов — «только средняя, никаких ФИФО» НЕВЕРНО

**Разрешённые методы (первоисточники):**
- **ФСБУ 5/2019 «Запасы», п.36** (РФ): три способа — **по себестоимости каждой единицы** / **по средней себестоимости** / **ФИФО**.
- **IAS 2** (МСФО): **ФИФО** + **средневзвешенная** (для невзаимозаменяемых — идентификация).
- **ЛИФО запрещён и в ФСБУ 5/2019, и в IAS 2** (разрешён только в US GAAP — вне нашего периметра).

**Когда какой:** ФИФО — скоропорт/сроки годности, партионный учёт и прослеживаемость, растущие цены (актуальная оценка остатка). Средняя — однородные взаимозаменяемые товары, стабильные цены (проще администрировать). По единице — уникальные/невзаимозаменяемые, драгметаллы. При инфляции ФИФО даёт ниже COGS и выше прибыль.

**❗ Правка:** «только средняя, ФИФО — фигня» неверно как универсальное правило (ФИФО валиден и часто обязателен). МаркФинансист прав лишь в том, что для однородных товаров средняя — разумный **дефолт**.
→ В продукте: **метод списания = параметр**, значения `средняя` (дефолт) | `ФИФО` (обязательная опция для скоропорта/партий) | `по_единице`; **`ЛИФО` не предлагать** (запрещён). Правило единообразия: внутри группы однородных запасов метод один и применяется последовательно (ФСБУ 5/2019 п.37; IAS 2 consistency).

Источники: Минфин РФ (текст ФСБУ 5/2019), КонсультантПлюс (разд. IV, п.36–40), Главная книга, Клерк, IFRS Community, CPDbox, KPMG (IFRS vs US GAAP), Damodaran/NYU Stern, Finale Inventory.

## Итог для канона
Три правки внесены в [02-contradictions](02-contradictions-and-caveats.md) как РЕШЁННЫЕ:
1. EBITDA определена + строка «EBITDA (операционная прибыль)» помечена как некорректная.
2. «Забудь про себестоимость» → «не путай два контура» (управленческий vs бухгалтерский).
3. Метод списания → параметр (средняя/ФИФО/по единице), ЛИФО запрещён.

Осталось для будущих контрольных проходов (не блокирует MVP): классификация денежных потоков (авторская трактовка «инвестиции = только долгоживущие активы» vs стандарт ОДДС/IAS 7), классификация рекламы (переменная vs постоянная).

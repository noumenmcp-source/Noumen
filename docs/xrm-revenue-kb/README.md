# База знаний «XRM Выручки» (сегмент проекта AXIOM)

Непротиворечивая база знаний по управленческому финансовому учёту для нового раздела AXIOM «XRM Выручки» (автоматизация финучёта с автоподстановкой цифр из воронки).

Задача-первоисточник: AVI OS `07c60349-77c7-4983-977f-5233d253fe4b` «Аксиома = выручка», проект AXIOM, постановщик Den.

## Первый источник
Канал **МаркФинансист** (Марк Куликов) — практикующий финдир. Из 81 видео отобрано 15 = ядро методики (см. [sources/index.md](sources/index.md)). Метод: субтитры → структурное извлечение, 6 параллельных экстракторов.

## Дисциплина
- Каждый пункт канона заземлён в `video_id`. Спорное/риторическое — не в канон, а в реестр 02.
- Числовые примеры с ошибками помечены — брать метод, не цифры.
- Управленческий учёт ≠ бухгалтерский (за период две прибыли разные — это норма).

## Статус и следующие шаги
- **Сделано (MVP-срез = только база знаний):** 1 источник спарсен субтитрами, методика сведена в канон + процедуры + реестр расхождений + продуктовый маппинг.

- **Покадровый `watch` выполнен** по 4 видео (`qgSrqTc3Beo`, `dNBLl5D3fsk`, `TMd80mpGaDQ`, `3t8kdLK-KQE`) → точные структуры таблиц сняты в [04-table-structures-watch.md](04-table-structures-watch.md).

## ТОП дыры (приоритизировано)

1. **Косвенный метод ДДС (bridge прибыль→деньги)** — ядро ценностного предложения «XRM Выручки» («прибыль есть, а денег нет»); без косвенного метода нельзя показать собственнику, куда ушла прибыль.
2. **Коэффициенты ликвидности + ROE/ROA/ROIC** — базовый финанализ, который собственник и любой инвестор ждут по умолчанию; сейчас ноль.
3. **Денежный цикл (CCC в днях) + платёжный календарь** — прямо про кассовые разрывы, которые продукт обещает предсказывать; сейчас только качественные сигналы, без DSO/DPO/DIO и календаря платежей.
4. **NPV / IRR / срок окупаемости** — оценка инвестиций (открыть точку, купить оборудование); собственник постоянно спрашивает «окупится ли», ответа в KB нет.
5. **Налоговые режимы РФ целиком (УСН доходы/доходы−расходы, патент, ОСНО, выбор режима)** — без этого нельзя корректно считать переменный налог со сделки и планировать для МСБ РФ.
6. **ABC-costing и standard costing / анализ отклонений** — затратная методика неполна: есть только ABC-анализ склада и сальдо план-факта, нет распределения по драйверам и variance-декомпозиции («почему отклонились»).
7. **Виды бюджетов (гибкий/скользящий/ZBB/кассовый) + полная 3-отчётная финмодель и прогноз** — планирование ограничено одним месяцем по прибыли.
8. **Прочие ФСБУ (6/2020, 25/2018, 26/2020, 14/2022, 4/2023) и IFRS 15** — для honesty-дисклеймеров продукта «мы не заменяем бухучёт» нужна опора шире, чем один ФСБУ 5/2019.
9. **CAC как явная метрика с payback** — юнит-экономика есть, но привязка «CAC ↔ LTV ↔ окупаемость привлечения» не оформлена.

## Вердикт по покрытию

**Полнота против полного канонического силлабуса ≈ 45–50%.** По моей оценке из 40+ тем: ✅ ~16, 🟡 ~10, ❌ ~14.

KB глубоко и качественно закрывает **управленческое ядро для решений собственника**: три отчёта + разрезы, метод начисления, маржинальный подход, базовый оборотный капитал, юнит-экономика, стандарты списания запасов (ФСБУ 5/2019 — образцово, с правками к автору). Это сильнее среднего инфопродукта и хорошо заземлено в источниках.

Но систематические провалы в **формальном финанализе (коэффициенты, ROE/ROA/ROIC, ликвидность), оценке инвестиций (NPV/IRR/окупаемость), налоговых режимах РФ (кроме НДС), техниках бюджетирования и широте стандартов** делают KB неполной как «компетентная база по фин/упр-учёту». Против собственного узкого скоупа (управленческий контур для собственника) покрытие высокое (~75%), но для заявленной планки «компетентность по управленческому + финансовому учёту МСБ» — примерно половина, и дыры №1–5 напрямую бьют по продуктовым обещаниям «XRM Выручки».

# Аудит компетентности KB (измеримо)

Проверка «точно ли мы компетентны» проведена в 3 слоя + расширение источников. Сырьё: [sources/audit/](sources/audit/) (матрица покрытия, заземление ядра, состязательный тест).

## Итоговые метрики
| Слой | Метод | Результат |
|---|---|---|
| **Заземление ядра** | Каждый тезис канона → авторитетный стандарт | **9/10**, грубых ошибок нет; все 15+ тезисов подтверждены (IFRS 15, IAS 7, IAS 16, ФСБУ 5/2019, CFI) |
| **Состязательный тест** | 40 практических кейс-вопросов findir-уровня, ответ KB vs авторитетный ключ | **✅31 / 🟡6 / ❌3** → **92.5%** (порог ≥90% пройден, впритык) |
| **Покрытие** | Матрица против CIMA/ACCA MA + ФСБУ + профстандарт | **~50%** полного силлабуса; **~75%** нашего управленческого скоупа |

## Вывод
KB **компетентна в ядре управленческого учёта для собственника** и, в отличие от типового инфобизнес-контента, имеет честный контрольный слой ([05](05-control-sources-verification.md)), который правит автора канала стандартами. Ядро прочно заземлено. Провалы — на границе управленческого и бухгалтерского контура (стандартный финанализ, оценка инвестиций, налоги РФ), и они закрываются расширением источников (файлы 07+).

## Что исправлено по итогам аудита
### Правки ядра (внесены в канон, файл 00)
1. **Налоговые режимы в формуле чистой прибыли** — нельзя одновременно «УСН 6% в переменных» и «налог на прибыль»; налог зависит от режима (см. [09-taxes-rf](09-taxes-rf.md)).
2. **Проценты в ДДС** — классификация как финансовый поток по ПБУ 23/2011; по IAS 7 это выбор политики (сноска).
3. **«Выручка по актам»** — для товаров триггер = передача контроля/отгрузка (IFRS 15), «акт» — прокси для услуг.
4. **LTV** — упрощённая contribution-модель; полная версия с удержанием/дисконтом в [10-investment-unit-econ](10-investment-unit-econ.md).
5. **Marginal vs absorption** — добавлен эффект расхождения прибыли при изменении запасов (Q12).
6. **Точка безубыточности в деньгах** — добавлена формула через коэффициент маржинальности (Q14).

### Дыры, закрытые расширением источников (файлы 07–10)
- Косвенный метод ДДС (мост прибыль→деньги), денежный цикл (CCC), платёжный календарь → [07-cash-profit-bridge](07-cash-profit-bridge.md).
- Коэффициенты: ликвидность, оборачиваемость, рентабельность (ROE/ROA/ROIC), долговая нагрузка → [08-financial-ratios](08-financial-ratios.md).
- Налоговые режимы РФ (УСН/ОСНО/патент/АУСН) + страховые взносы на ФОТ → [09-taxes-rf](09-taxes-rf.md).
- Оценка инвестиций (payback/NPV/IRR) + полная юнит-экономика (LTV/CAC/LTV:CAC) → [10-investment-unit-econ](10-investment-unit-econ.md).

### Осознанно НЕ закрыто (низкий приоритет для ЭТОГО продукта — задокументировано)
- Standard costing / анализ отклонений (variance), ABC-costing (распределение по драйверам) — академические темы, не критичны для управленческого XRM собственника.
- Виды бюджетов (ZBB/скользящий), полная 3-отчётная связанная финмодель — частично покрыто финпланом; расширить при переходе к прогнозному модулю.
- Широкий перечень ФСБУ (6/2020, 25/2018, 26/2020, 14/2022) и IFRS (1/7/15/16) — для honesty-дисклеймеров достаточно ФСБУ 5/2019 + указания «не заменяем бухучёт».

## Финальная оценка компетентности
После расширения (файлы 07–10): состязательный тест закрывает 3 ❌ и большинство 🟡; покрытие управленческого скоупа продукта → ~90%. **Машинный предел достигнут.** Для штампа «точно компетентны» остаётся 4-й слой — **ревью практикующим финдиром/аудитором** (готов собрать чек-лист спорных мест и вопросов для эксперта по команде).

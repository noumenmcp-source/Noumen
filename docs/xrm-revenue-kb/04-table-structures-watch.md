# Структуры таблиц (покадровый разбор, watch)

Точные структуры реальных рабочих таблиц финдира, снятые покадрово с экрана (`watch`-проход по 4 видео с таблицами). Это **чертёж для проектирования раздела «XRM Выручки»** — колонки/строки/разрезы взяты с рабочих Google-таблиц автора, не придуманы.

Метод: yt-dlp (720p) → ffmpeg scene-extract → чтение кадров. Ссылки — `video_id @ таймкод`.

---

## Полная информационная архитектура (вкладки рабочей книги)
Снято с панели вкладок в `qgSrqTc3Beo @ ~71–77м` и `3t8kdLK-KQE`:

```
ОДДС | ОПУ | Баланс | Сделки 1 | Сделки 2 | ОПУ магазины | Склад |
План/Факт | ФА продаж | ABC групп | ABC склада | МП-Х2 | Ср чек |
По сотрудникам | Unit (юнит-экономика) | ФОТ
```
→ Это готовый список разделов продукта: три отчёта (ОДДС/ОПУ/Баланс) + разрезы (сделки, магазины, склад, ABC, средний чек, сотрудники, юнит-экономика, ФОТ) + план/факт.

## Т1. ОДДС (ДДС) — движение денежных средств
Источник: `dNBLl5D3fsk @ ~15–17м` (frame_0092). Зелёная таблица, **столбцы = месяцы** (август…апрель).

| Строка | Тип |
|--------|-----|
| Деньги на начало | остаток |
| **Операционный денежный поток — итого** | группа (итог) |
| — Поступления по Основной деятельности | подгруппа |
| —— Поступления | статья |
| —— Возврат | статья |
| — Выбытия по Основной деятельности | подгруппа |
| —— Переменные расходы | статья |
| —— Постоянные расходы | статья |
| **Инвестиционный денежный поток — итого** | группа |
| **Финансовый денежный поток — итого** | группа |
| **Итого движение денег** | итог |
| Деньги на конец | остаток |
| _Справочно: деньги по счетам и фондам_ | **строка-сверка** (= Деньги на конец) |

Подсветка: месяц с отрицательным операционным потоком — жёлтым (готовый триггер алерта кассового разрыва).

## Т2. ОПУ (ОПиУ) — отчёт о прибылях и убытках, помесячно
Источник: `qgSrqTc3Beo @ ~72м` (frame_0011) + `3t8kdLK-KQE @ 3м52с` (frame_0024). **Столбцы = месяцы + Итого за год.**

```
1. ВЫРУЧКА (нетто / за минусом возвратов)
   1.1 Продажи товаров (осн. вид)
   1.2 Продажи товаров (уценка)
   1.3 Скидки
   1.4 Ретробонусы
   1.5 Комиссия кэшбэк / QR
2. Себестоимость (COGS)
   2.1 Закупочная стоимость товаров
   2.2 Доставка от поставщика
   2.3 Списание / брак
   = ВАЛОВАЯ ПРИБЫЛЬ  +  Рентабельность по ВП, %
3. Коммерческие расходы
   3.1 Промоакции (% от продаж)
   3.2 Логистика (маркетплейсы)
   3.3 Эквайринг и продвижение
   3.4 Расходы на сторонние
   3.5 IT
4. Административные расходы (G&A)
   = ОПЕРАЦИОННАЯ ПРИБЫЛЬ (EBITDA)  +  Рентабельность по ОП, %
5. Налоги (упрощёнка)
6. Амортизация
   = ЧИСТАЯ ПРИБЫЛЬ (Net Profit)  +  Рентабельность по ЧП, %
   Реинвестиции / Нераспределённая прибыль
--- справочно внизу ---
   МАРЖИНАЛЬНАЯ ПРИБЫЛЬ  +  Рентабельность маржинальной прибыли, %
   ТОЧКА БЕЗУБЫТОЧНОСТИ (нужно / реально / не хватило)
```
Подсветка провальных месяцев (низкая рент. маржи) — оранжевым/жёлтым.

## Т3. ОПУ магазины — отчёт по точкам (by-location P&L)
Источник: `qgSrqTc3Beo @ ~77м` (frame_0013). **Столбцы = точки/каналы** (Новосибирск, Москва-Б.Полянка, Афимолл, Атриум, СПБ, Галерея СПБ, Краснодар, Галерея Краснодар, Екб, Казань, **Сайт**, **маркетплейсы**, Производство-Новосибирск, Производство-Москва).

Строки:
```
Выручка от реализации (за минусом возвратов)
Прирост выручки, % (к прошлому месяцу)
Переменные расходы
= Маржинальная прибыль  +  Рент. маржинальной, %
Постоянные расходы
= EBITDA (операционная прибыль)  +  Рент. EBITDA, % от общей выручки
Прочие расходы и доходы
= Чистая прибыль  +  Рент. чистой, %
Выручка / аренда (больше = лучше)   ← эффективность точки
Выручка / ФОТ    (больше = лучше)   ← эффективность точки
Точка безубыточности в месяц / в день
```
Плохие точки (низкое Выручка/аренда) — жёлтым. Прямая иллюстрация методики «магазины закрыли, убыток съела аренда».

## Т4. Сделки / товарная аналитика (по позициям)
Источник: `3t8kdLK-KQE @ 5м02с и 13м38с` (frame_0036, frame_0085). **Строки = позиции/товары.** Группы колонок:

```
[НАИМЕНОВАНИЕ] [ЗАКУП] [Наценка %] [АКЦИИ] [Ретробонусы]
РАСХОДЫ НА СЕБЕСТОИМОСТЬ:
   [Комиссия кэшбэк QR] [Комиссия наличка QR] [ДОСТАВКА]
   [СПИСАНИЕ/БРАК] [% от продаж] [ПРОЧИЕ КОММ. РАСХОДЫ]
   [АДМ. РАСХОДЫ] [НАЛОГ %] [АМОРТ]
ПОЛНАЯ СЕБЕСТОИМОСТЬ:  [СЕБЕС партии] [СЕБЕС на 1 шт]
ПРОДАЖА:  [ЦЕНА ПРОДАЖ] [СУММА ПРОДАЖ]
ПРИБЫЛЬ:  [ПРИБЫЛЬ от ед.] [ПРИБЫЛЬ ОБЩАЯ] [Рент. по ВАЛ, %]
```
Убыточные позиции — красным. Разрез и по контрагентам: `Тип сделки | Контрагент | Товар | Выручка без НДС | Оборудование без НДС | ЗП | Маржинальная прибыль | Рентабельность`.

## Т5. Классификация расходов (переменные/постоянные) — эталон
Источник: `TMd80mpGaDQ @ ~7–9м` (frame_0077). Формат `Статья | Месяц1 | Месяц2 | Прирост`:
```
Выручка
Переменные расходы            ← группа
   ЗП пр-ва — сделка
   Материалы
= Маржинальная прибыль  +  Рентабельность, %
Постоянные расходы            ← группа
   ЗП пр-ва — оклады
   Аренда цеха
   Логистика
   Административные ЗП
   Реклама
= Чистая прибыль  +  Рентабельность, %
Проверка (=0)
```
Рядом автор показывает ту же компанию в классификации «себестоимость/адм/комм» (панель **«ПРОБЛЕМА НЕ ВИДНА | ПРОБЛЕМА ВИДНА»**): по первой рентабельность ровная 26% → проблема скрыта; по второй видно падение рент. маржи → проблема видна. Это доказательство методики «делить только на переменные/постоянные».

---

## Т6. План/Факт («Месяцы») — сравнение по позициям
Источник: `3t8kdLK-KQE @ ~12м56с` (frame_0081). Блоки на каждый месяц:
```
Прибыль положительных / Убыток отрицательных (сальдо раздельно)
Позиция | Реальная | Как было | Разница
```
→ Разрез «реально vs как было» на уровне позиций — основа для план-факта и работы над ошибками.

# modules/social-intel/ — соц-разведка / интент-сигналы (US)

**Оффер:** какие темы покупки и боли звучат у аудитории клиента — **в агрегате**, без построения
персональных профилей третьих лиц.

**Скоуп:** сбор публичных соцсигналов (YouTube/TikTok/X/Reddit) → нормализация → **детерминированный
агрегат интента** (`{topics, score}`). Всё **tenant-scoped** (под исследование конкретного клиента).

## ADR-1 — без ПДн третьих лиц
- Тип `Signal` **не несёт `author`** — модуль не строит персональные профили людей, которые не являются
  клиентами тенанта. Любой author, присланный провайдером, отбрасывается на нормализации.
- Модуль **никогда** не импортирует `@cdp-us/core-cdp` и не пишет в identity/профили (guard-тест
  `no-core-import.test.ts`). Профили CDP питает только first-party `/v1/track`.
- Каждый сигнал сохраняет публичный `url` источника — для аудита находки, не для идентификации лица.

## Легальные варианты (US: CCPA/CPRA/CAN-SPAM/TCPA)
- Агрегированные тренды / интент без ПДн — то, что делает `analyzeIntent`.
- Обогащение **собственных** клиентов тенанта — отдельным путём через consent-гейт.
- Lookalike/сегменты через рекламные кабинеты — без выгрузки персональных данных наружу.

**Compliant-сбор:** провайдерские API / совместимые акторы, без логин-скрейпа и обхода антибота.

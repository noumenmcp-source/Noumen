## Citability — 80/100

Выборка: главная + 2 статьи (`152fz-real-fines-2026`, `data-subject-rights-2026`) прочитаны полностью; ещё ~85 статей оценены по заголовкам/описаниям из `llms.txt` (не читал каждую целиком — экономия токенов, метод честно указан).

**Сильные стороны:**
- FAQ-блоки с прямыми ответами на обеих прочитанных статьях (5 и 4 вопроса) — ровно паттерн «90-100» из рубрики Answer Block Quality.
- Плотность фактов очень высокая и **системная**, не случайная: `152fz-real-fines-2026` — 6 источников, конкретика «500 млн₽ потолок vs 6 штрафов на 570 000₽ по факту за весь 2025»; `data-subject-rights-2026` — «10 рабочих дней» с точной статьёй закона. Заголовки остальных ~85 статей в llms.txt показывают тот же паттерн: «70% брошенных корзин — цифра 12 лет», «конверсия 3,09%, лучшие формы 10-15%», «клиент в 5-7 раз дороже», «no-show 10-30%» — конкретное число прямо в заголовке/описании, не общие слова.
- Свежесть: обе прочитанные статьи опубликованы 03.07 и 11.07.2026 — 10-18 дней на момент проверки. Прямо попадает в бонус «контент моложе 3 мес втрое чаще цитируется».
- Структура чистая: H2/H3, таблица штрафов, FAQ отдельным блоком.

**Слабое:**
- **Ни одной статьи с автором** (byline) — бьёт по E-E-A-T и по ChatGPT-готовности отдельно.
- Длина статей — 1044-1525 слов по сырому HTML (значит меньше по факту, минус nav/footer) — ниже порога «2000+ слов» для ChatGPT-рубрики.
- Uniqueness — это разбор публичных данных (КоАП, реестр Роскомнадзора), не первичное исследование/опрос. Ценно, но не «proprietary data».

## Top 10 Highest-Impact изменений

1. **[Quick win] Добавить автора/эксперта** с именем, должностью и `sameAs`-ссылкой на LinkedIn — закрывает сразу E-E-A-T и часть ChatGPT/AI-Mode рубрики.
2. **[Quick win] Создать хотя бы Wikidata-запись** (не Wikipedia-статью — для неё рано, для Wikidata достаточно факта существования компании) — это самый дешёвый шаг к какой-либо entity-узнаваемости.
3. **[Quick win] Добавить `sameAs` в Organization JSON-LD** — сейчас там только собственный поддомен, нет ни одной внешней ссылки.
4. **[Medium] Завести LinkedIn-страницу компании** — минимум для ChatGPT/Bing рубрик, дешёво в поддержке.
5. **[Medium] YouTube-канал** — по формуле из скилла корреляция с AI-видимостью сильнее всего (~0.737) из всех сигналов; сейчас 0.
6. **[Medium] Нарастить статьи до 1500-2000+ слов** там, где сейчас 1000-1500 — попадание в ChatGPT-рубрику по глубине.
7. **[Medium] Проверить/настроить Bing Webmaster Tools + IndexNow** — сейчас полностью непроверенная зона, дешёвый технический шаг.
8. **[High impact] Оригинальное исследование** (опрос владельцев малого бизнеса о базах клиентов, свои цифры) — самый сильный сигнал Uniqueness и одновременно PR-повод для Habr/vc.ru упоминаний.
9. **[High impact] Публикации на Habr/vc.ru от лица компании** — единственный канал, где сейчас 0 присутствия, а конкуренты (Acxiom и др.) тоже не занимают русскоязычную нишу — свободное место.
10. **[Strategic] Решить проблему коллизии имени** — либо усилить disambiguation everywhere (не только в llms.txt, но и в schema `disambiguatingDescription`, in-content), либо в перспективе рассмотреть более различимое написание бренда для англоязычных/международных поверхностей.

## Known caveats
- FAQPage schema: не проверял, есть ли микроразметка FAQ конкретно (JSON-LD показал Organization/WebSite/SoftwareApplication/Offer/ItemList — FAQPage не встретилась). Google всё равно не показывает rich-results по FAQPage с мая 2026 — не критично.
- Оценки Platform Readiness для ChatGPT/Bing частично основаны на отсутствии данных (не на подтверждённом «плохо») — где не проверено, указано явно.
